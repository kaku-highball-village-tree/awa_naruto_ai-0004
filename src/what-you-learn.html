阿波なるとAI塾って何を学べるの？

ChatGPT、Gemini、Claudeなどの生成AIを実際に使いながら、主に次の3つを学びます。

  • AIを使いこなす力
  • AIを使って、自分自身の知識・技能・専門性を高める力
  • AIを使いこなすために、パソコン・スマートフォンをより高度に使いこなす力

阿波なるとAI塾は、生成AIの使い方だけを学ぶ塾ではありません。

一人ひとりの目的や経験、習熟度に合わせて、必要な内容から学べる個別指導の塾です。

たとえば、

  1. AIを使いこなす力を身につけたい方

    AIに目的や条件を分かりやすく伝えたり、必要な情報や資料を与えたり、会話を重ねながら内容を改善したり、複数のAIやソフト、ファイル、サービスを組み合わせたりすることで、AIをより思いどおりに、実践的に使いこなす力を学びます。

  2. AIを使って、自分の仕事や専門分野を深めたい方、学校の勉強をしたい方

    AIを使って、仕事や専門分野、資格取得、学校の学習、語学などの知識や技能を高めることができます。

    また、学校の学習では、情報Ⅰや、中学校の技術・家庭科の技術分野で学ぶ「情報の技術」などをAIを使って学び、共通テストの情報Ⅰで高得点を目指します。

    さらに、情報科目以外でも、国語・数学・英語・理科・社会などの基本五教科について、数学の問題演習、英語の文法や語彙、理科・社会の暗記や理解、国語の読解など、AIを使いながら学習する方法を学ぶことができます。

  3. パソコンやスマートフォンの基本操作から学びたい方

    文字入力、インターネット、メール、アプリ、ファイル操作、Word、Excel、PowerPointなど、パソコン・スマートフォンの使い方を学べます。すぐにAIまで進まなくてもかまいません。

  4. パソコン・スマートフォンをより高度に使いこなしたい方

    ショートカットキー、ファイルやフォルダの管理、PDFやCSVなどのファイル形式、Word、Excel、PowerPoint、画像編集、クラウドサービス、データの整理・分析などを学び、AIと組み合わせて、仕事や学習により実践的に活用できるようになります。

  5. ビジュアルプログラミングを学びたい方

    主に小学生や中学生を対象に、ViscuitやScratchなど、絵やブロックを使って学ぶビジュアルプログラミングに取り組みます。

    ViscuitやScratchは、小学校のプログラミング教育でも活用されており、中学校を含む学校教育の場でも使われています。初めてプログラミングを学ぶ子どもでも、絵やブロックを使いながら、プログラムの考え方や基本的な仕組みを学ぶことができます。
    文部科学省ホームページ

  6. 本格的なプログラミングを学びたい方

    Python、C言語、C++、C#、Excel VBAなどを学べます。AIを学ばずに、プログラミングだけを学ぶこともできます。

  7. ホームページ作成を学びたい方

    HTML、CSS、JavaScriptを使ったホームページ作成を学べます。

全員が同じ内容を同じ順番で学ぶのではなく、一人ひとりの目的や現在の習熟度に合わせて、必要な内容を選んで学びます。

AIそのものの進化

ChatGPT、Gemini、Claudeなどの生成AIは、急速に進化しています。

AIそのものが賢くなり、以前は細かく条件を指定しなければうまくできなかったことでも、現在では、より簡単な指示でできるようになることがあります。

たとえば、1年前には、

「この条件を守って、この形式で、この順番で……」

と細かく指示しなければ期待した結果が得られなかったことが、AIの性能向上によって、

「これを分かりやすくまとめて」

という比較的簡単な指示でも、意図をくみ取って適切な結果を返せるようになることがあります。

これは、ユーザーの能力が上がったからではありません。AIそのものが進化したことによって、同じ人が同じような指示をしても、以前より高度なことができるようになったということです。

AIの進化そのものはユーザー側で進めるものではありませんが、新しいAIや新しい機能が登場することで、ユーザーが利用できる可能性は広がっていきます。

ユーザーのAI活用スキルの向上

一方で、AIそのものの進化とは別に、AIをより高度に活用するためには、AIを使うユーザー自身も成長していく必要があります。

その一つが、AI活用スキルの向上です。

AIを使い続けることで、AIへの質問や指示の仕方が上手になり、AIをより使いこなせるようになります。

最初は、

「AIに質問して答えてもらう」

という使い方から始まっても、慣れてくると、

  • 目的や条件を分かりやすく伝える
  • AIと何度も会話しながら内容を改善する
  • AIに役割や立場を設定して、回答の方向性を調整する
  • 例や見本を示して、求める回答に近づける
  • 必要な情報や前提条件をAIに与える
  • 過去の会話、資料、ファイルなどを活用し、AIに必要な背景情報を与える
  • 複雑な作業を小さな手順に分けて進める
  • AIに作業手順やルールを与えて処理してもらう
  • AIに途中経過や結果を確認させ、ミスを減らす
  • 複数のAI、ソフト、ファイル、サービスなどを組み合わせて活用する
  • 文章、画像、資料などを一緒に作る
  • 調査や分析に利用する
  • AIを使ってプログラムを作る
  • AIを使って業務を効率化・自動化する

など、より高度な使い方ができるようになります。

これは、ユーザーがAIを使いこなせるようになることによるスキルアップです。

AIを使って、自分自身の知識・技能・専門性を高める

もう一つは、AIとは別に、自分自身の知識や技能、専門性を高めることです。

自分が利用したい分野についての知識が増えると、AIに何を頼めばよいのかが分かるようになります。また、その分野で使われる専門用語や考え方、表現方法も身につくため、AIへの指示そのものが、以前より具体的で高度になります。

たとえば、最初は、

「これを分かりやすくしてください」

という指示しかできなかった人でも、その分野について学ぶことで、

「この条件を優先してください」
「この方法と別の方法を比較してください」
「この前提条件ではなく、別の条件で考えてください」

といった、より具体的な指示ができるようになります。

さらに、知識や専門性が高まると、過去の自分では知らなかった専門用語や言い回しを、自分からAIへの指示の中で使えるようになります。

その結果、AIに対してより正確に意図を伝えたり、より専門的な内容を依頼したりできるようになります。

たとえば、仕事で使うのであれば、業務の流れや専門用語を知っているほど、具体的な指示ができます。プログラミングであれば、変数、関数、例外処理、アルゴリズム、クラス設計などの知識が増えるほど、AIへの指示もより専門的になります。

つまり、

知識が増える → 使える言葉が増える → 指示が高度になる → AIから得られる成果も高度になる

という流れで、AIを活用する力も高まっていきます。

そして、この自分自身の知識・技能・専門性そのものも、AIを使って高めていくことができます。

分からないことをAIに質問したり、具体例を出してもらったり、練習問題を作ってもらったり、自分の答えや考え方を確認してもらったりすることで、自分の理解度やペースに合わせて学ぶことができます。

AIを学習相手として活用することで、新しい知識を身につけたり、苦手な部分を繰り返し学んだり、より高度な内容へ進んだりすることができます。

つまり、AIを使って自分自身の知識・技能・専門性を高め、その成長によって、さらにAIへ高度な指示を出せるようになるという循環が生まれます。

AIを使いこなすために、パソコン・スマートフォンをより高度に使いこなす

AIをより実践的に活用するためには、AIそのものの使い方だけでなく、パソコンやスマートフォンを使いこなす力も重要です。

AIに質問したり、文章を作ってもらったりするだけであれば、基本的な操作でも利用できます。

しかし、AIを仕事や学習に本格的に活用しようとすると、

  • AIが作った文章を保存・編集する
  • WordやPowerPointで資料にまとめる
  • Excelでデータを整理・分析する
  • 画像を保存・編集する
  • PDFやCSVなどのファイルを扱う
  • ファイルをAIに読み込ませる
  • AIが作ったデータを別のソフトで利用する
  • 複数のアプリやサービスを組み合わせる
  • ダウンロードしたファイルを整理する
  • 必要な情報をインターネットから探してAIに渡す

といった操作が必要になります。

そのため、パソコンやスマートフォンを使いこなせるようになるほど、AIを活用できる範囲も広がっていきます。

たとえば、最初はAIとの会話だけで利用していた人でも、パソコンやスマートフォンの操作に慣れてくると、

「このExcelファイルを分析してください」
「このPDFを読んで、必要な情報を整理してください」
「作成した文章をWordで使える形にしてください」
「この画像を資料に入れてください」

といった、より実践的な使い方ができるようになります。

つまり、

パソコン・スマートフォンを使いこなす力が高まる
↓
扱えるファイルやソフトが増える
↓
AIと組み合わせてできることが増える
↓
AIをより実践的に活用できるようになる

という流れです。

  • メール

  • ファイルやフォルダの管理
  • ダウンロード、アップロード
  • 情報セキュリティ

  • ブラインドタッチ（タッチタイピング）
  • ショートカットキー
  • さまざまな文字や記号の入力
  • テキストエディタ

  • クラウドサービス
  • データの整理・分析

AIを使いこなす力と、パソコン・スマートフォンを使いこなす力は、相互に関係しています。

AIが良い回答を出しても、その結果を保存したり、加工したり、他のソフトで利用したりできなければ、活用できる範囲は限られてしまいます。

阿波なるとAI塾では、「AIの使い方を学ぶ」「AIを使って自分自身の知識・技能・専門性を高める」「パソコン・スマートフォンをより高度に使いこなす」ことを組み合わせ、一人ひとりが自分の目的に合わせてAIを活用できるようになることを目指します。

一人ひとりに合わせた個別指導

阿波なるとAI塾は、全員が同じ教材を使って、同じ内容を同じ順番で学ぶ授業ではありません。

一人ひとりの目的、経験、習熟度に合わせた個別指導の塾です。

特に、

AIの活用スキル

パソコン・スマートフォンの習熟度

自分が学びたい分野の知識・技能・専門性

は、人によって大きく異なります。

たとえば、

「パソコンは得意だけれど、AIは初めて」

という方なら、パソコンは応用的な内容から、AIは入門から始めることができます。

反対に、

「AIはある程度使えるけれど、Excelやファイル操作が苦手」

という方なら、AIは応用を続けながら、パソコンについては基礎から学ぶことができます。

また、

「仕事でExcelをもっと使えるようになりたい」
「資格取得のためにAIを使って学習したい」
「自分の仕事の専門知識とAIを組み合わせたい」

といった場合には、その人の目的に合わせて学ぶ内容を選びます。

希望に応じてプログラミングも学べます

プログラミングは、全員が必ず学ぶ内容ではありません。

プログラミングを学びたい方や、仕事・学習で必要な方には、一人ひとりの経験や目的に合わせて指導します。

一方で、AIの活用やパソコン・スマートフォンの使い方を中心に学びたい方は、プログラミングを無理に学ぶ必要はありません。

また、AIは学ばず、プログラミングを中心に学ぶこともできます。

学習する場合は、初心者から経験者まで、一人ひとりの習熟度や目的に合わせて進めます。

ViscuitやScratchなど、学校でも使われる、絵やブロックを使って学ぶビジュアルプログラミングから、Python、C言語、C++、C#、Excel VBAなどの本格的なプログラミング、HTML、CSS、JavaScriptを使ったホームページの作り方まで学ぶことができます。

たとえば、

  • Viscuit
  • Scratch
  • Python
  • C言語
  • C++
  • C#
  • Excel VBA
  • HTML
  • CSS
  • JavaScript
  • ホームページの作成
  • 変数
  • 条件分岐
  • 繰り返し
  • 配列
  • 関数
  • アルゴリズム
  • プログラム設計
  • エラーの原因の調査と修正
  • AIを活用したプログラミング
  • 業務の自動化

などを学ぶことができます。

AIを活用しながらプログラミングを学ぶ場合も、AIにプログラムを書いてもらうだけではなく、自分自身も内容を理解しながら使えるようになることを大切にします。

自分の知識が増えるほど、AIに対して、

「この処理を関数に分けてください」
「例外処理を追加してください」
「このアルゴリズムを別の方法に変更してください」

など、より具体的で高度な指示ができるようになります。
